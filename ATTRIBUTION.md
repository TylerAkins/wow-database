## Wowhead Forever

The canonical JSON snapshot was gathered from Wowhead Forever quest, zone, object, and item pages. Quest names, coordinates, NPC and object identifiers, classifications, and other game data belong to their respective sources. This repository stores converted records for programmatic use and does not claim ownership of that data.

- Source: https://www.wowhead.com/forever
- Initial migration source: https://github.com/TylerAkins/forever-quest-markers
- Initial migration commit: `43f22e73ff3bf19f564d20d1e6846b0d57dbd3de`

Wowhead is not bundled and is not required to read the committed raw or compiled JSON files.

## QuestieDB Forever

The Forever overlay and its derived quest collections use effective enUS records from [QuestieDB](https://github.com/Questie/QuestieDB) at commit [`cac1eff815923f896d082764d023cf812454a023`](https://github.com/Questie/QuestieDB/tree/cac1eff815923f896d082764d023cf812454a023). They include QuestieDB-authored corrections and player-trace-derived data. The owner of this repository stated they have permission to reuse QuestieDB data for this import. QuestieDB's data remains attributed to its contributors and underlying game sources; this repository does not relicense it.
